# 분석 공식과 신호등 규격

## 1. 공통 원칙

- 기준 기간과 비교 기간의 길이는 같아야 한다.
- 값이 없는 기간은 0으로 가정하지 않는다.
- 모든 계산 결과에 데이터 출처와 기간을 표시한다.
- 신호등은 색뿐 아니라 `정상/주의/위험/데이터 없음` 텍스트를 함께 표시한다.

## 2. 전주 대비 변화율

```text
변화율(%) = (이번 주 값 - 전주 값) / 전주 값 × 100
```

예외:

- 전주 데이터 없음: 회색, 비교 불가
- 전주 0이고 이번 주 양수: 신규 발생으로 표시, 무한대 계산 금지
- 이번 주 데이터 없음: 회색, 업로드 필요

### 기본 신호등

- 초록: 변화율 > -5%
- 노랑/주황: -10% < 변화율 <= -5%
- 진한 빨강: 변화율 <= -10%
- 회색: 비교 데이터 없음

비즈머니는 변화율보다 절대 잔액/예상 소진일 기준을 우선한다. 임계값은 매장별 일예산과 운영 규칙으로 설정 가능하게 한다.

## 3. 운영 대시보드 최근 4주

- `W0`: 선택 기준일이 속한 월요일~일요일
- `W1`: 1주 전
- `W2`: 2주 전
- `W3`: 3주 전

표시 대상:

- 플레이스 유입
- 검색광고 클릭/CPC
- 파워링크 노출
- 순매출
- 추후 검증된 신규/재방문 지표

## 4. 네이버 검색광고

```text
CTR(%) = 클릭수 / 노출수 × 100
CPC = 광고비 / 클릭수
전환율(%) = 전환수 / 클릭수 × 100
CPA = 광고비 / 전환수
```

분모가 0이면 0으로 꾸미지 않고 `계산 불가`로 표시한다.

## 5. 플레이스 주간 CSV

- 총 유입: CSV 요약의 전체 유입 합계
- 키워드 유입: 같은 키워드의 기간 내 유입 합계
- 채널 유입: 같은 채널의 기간 내 유입 합계
- 증감: 선택 기간과 직전 동일 길이 기간 비교
- 주간 조회: 월요일~일요일 업로드 단위
- 월간 조회: 해당 월에 포함된 최신 주간 revision 합계

## 6. 여신금융 승인내역

```text
순매출 = 승인금액 합계 - 취소금액 합계
순결제건 = 승인건수 - 정상 연결된 취소건수
결제 1건당 금액 = 순매출 / 순결제건
```

그래프:

- 날짜별: 막대=순매출, 선=순결제건
- 시간대별: 시간별 순매출과 순결제건
- 요일별: 월~일 순매출/건수
- 평일/주말: 매출과 결제 1건당 금액 비교

### 신규/재방문 주의

마스킹 카드번호는 고유 고객 ID가 아니다. 따라서 현재 데이터로 만든 신규/재방문은 `결제키 기준 추정`으로만 표시하거나 MVP에서는 숨긴다. 실제 고객 기준 분석은 CRM 전화번호 해시, POS 고객키 등 안정적인 식별자가 확보된 뒤 활성화한다.

## 7. 목표매출 기반 필요수 계획

### 현재 데이터

- 현재 월매출
- 현재 결제 1건당 금액 또는 검증된 객단가
- 현재 신규/재방문 수와 재방문률: 검증된 고객키가 있을 때만

### 사용자 입력

- 목표까지 개월 수 `N`
- 목표 월매출
- 목표 객단가
- 목표 재방문률
- 테이블 수
- 종합 CAC

### 월별 선형 목표

현재값을 `C`, 목표값을 `T`, 월을 `m`이라 하면:

```text
월 m 목표 = C + (T - C) × m / N
```

월별 필요 결제건:

```text
필요 결제건 = 월 목표매출 / 목표 객단가
```

검증된 고객키가 있을 때:

```text
필요 재방문 고객 = 필요 총고객 × 목표 재방문률
필요 신규 고객 = 필요 총고객 - 필요 재방문 고객
```

현재 여신 데이터만 사용할 때는 `고객` 대신 `결제건`으로 표기한다.

### 광고비 시나리오

```text
필요 광고비 = 추가로 필요한 신규 고객 수 × 종합 CAC
```

종합 CAC는 직원이 직접 입력하고, 실제 광고 데이터가 연결되면 채널별 CAC로 분리한다.

### 테이블 수 참고

```text
일 필요 결제건 = 월 필요 결제건 / 영업일수
테이블당 일 필요 회전 = 일 필요 결제건 / 테이블 수
```

이는 운영 목표를 보는 참고 시나리오이며 실제 고객 수나 매출을 보장하지 않는다.

## 8. 매장 세팅 진행률

- 0~29%: 진한 빨강
- 30~59%: 주황
- 60~79%: 노랑
- 80~100%: 초록
- 미완료이며 마감일 경과: 진행률 색보다 진한 빨강 경고 우선
- 미완료이며 마감 당일: 주황 경고
