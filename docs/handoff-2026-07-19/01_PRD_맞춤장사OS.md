# 맞춤장사 OS 통합 PRD

## 1. 프로젝트 개요

### 문제

마케팅 대행사는 여러 음식점 계정, 광고, 플레이스, 업무 약속, 주간 보고와 매출 데이터를 분산된 도구로 관리한다. 대표는 직원 업무를 일일이 확인해야 하고, 직원은 매장마다 무엇을 했는지 놓치기 쉬우며, 사장님은 비용을 지불한 가치를 한눈에 체감하기 어렵다.

### 목표

음식점 사장님이 마케팅을 매일 공부하지 않아도 고객이 검색하고 비교하고 방문하고 재방문할 수 있는 구조를 90일 안에 세팅한다. 대표의 판단을 표준 업무로 만들고, 직원이 같은 품질로 수행하며, 사장님에게 데이터와 증빙으로 진행상황을 보여준다.

### 제품 영역

1. **회사직원용 Admin OS**: 매장, 업무, 세팅, 광고, 플레이스, 매출, 보고서 관리
2. **사장님용 대시보드**: 미션, 진행률, 성과, 회사가 한 일 확인
3. **고객 참여 QR 미니웹앱**: 동의, 설문, 포인트, 이벤트, 자발적 리뷰 안내, CRM

### MVP 성공 기준

- 등록된 모든 매장이 한 개의 `store_id`로 연결된다.
- 직원 업무와 완료 증빙이 DB에 남고 주간 보고서에 반영된다.
- 플레이스 CSV와 여신금융 XLS를 주기적으로 누적 업로드할 수 있다.
- 운영 대시보드에서 매장별 위험 신호를 실제 데이터로 판단한다.
- 사장님에게 MID 기반 읽기 전용 보고서 링크를 제공한다.

## 2. 사용자 시나리오

### 대표/관리자

전체 매장의 관리 주차, 담당자, 비즈머니, 플레이스 유입, 매출, 업무 누락을 표에서 확인한다. 위험 매장을 먼저 정렬하고, 관리자 일일 루틴과 매니저 업무 이행을 점검한다.

### 실무 매니저

담당 매장의 계정과 정보안내문을 확인하고, 일일 약속 업무와 주간 표준업무를 수행한다. 사진/텍스트 증빙을 남기며, CSV/XLS를 업로드하고 키워드를 조합·분석한다.

### 클라이언트 사장님

읽기 전용 링크로 4주 업무 진행, 키워드 순위, 유입, 리뷰, 매출과 고객 지표를 확인한다. 회사가 한 일과 자신이 해야 할 미션을 구분해서 본다.

### 매장 직원/방문 고객

매장 직원은 일마감과 현장 미션을 입력한다. 방문 고객은 QR 이벤트에서 동의 후 만족도 설문과 이벤트에 참여하고 자발적으로 리뷰 경로를 선택한다.

## 3. 핵심 기능 목록

### MVP 필수

1. 로그인과 관리자/직원/사장님 권한
2. 매장 일괄/개별 등록, MID, 담당자, 4주 관리주기
3. 매장별 계정/링크/내부 메모/영업 히스토리
4. 일일 업무 수집함, 우선순위, 마감일, 완료 이력
5. 관리자 요일별 루틴 체크리스트
6. 1~4주 표준업무, 증빙, 수정/추가/삭제
7. 정보안내문 질문 양식과 사장님 작성 링크
8. 네이버 플레이스 주간 CSV 누적 업로드 및 비교
9. 여신금융 XLS 원장, 순매출/결제건/시간·요일 분석
10. 키워드 1~6 그룹 조합, 50개/1000개 CSV
11. 검색광고 검색량 조회와 지도 저경쟁 후보 탐색
12. 사장님 보고서 미리보기와 읽기 전용 공유 링크

### 2차

- 네이버 검색광고 잔액/성과 자동 수집
- 플레이스 순위 정기 워커
- 리뷰 AI 분석
- QR 이벤트/CRM과 고객 DB
- 목표매출 기반 고객 시나리오 및 광고 예산 추천
- PDF 주간/월간 보고서

### 제외 또는 승인형

- 여신금융/플레이스 자동 로그인 수집
- 광고 완전 자동 집행
- 마스킹 카드번호 기반 실제 개인 식별
- 법적 효력이 있는 노무/세무/권리금 판단

## 5. 상세 기능 명세

### 매장 원장

- 매장명, 클라이언트명, 업종, 지역, 담당자, 관리 시작 월요일, 계약 주수, MID를 관리한다.
- 네이버 플레이스 URL, 사장님 보고서 URL, 정보안내문 URL을 MID와 연결한다.
- 재계약 감도, 사장님 성향, 핵심 니즈, 핵심 불안, 영업 대화 요약을 내부 정보로 관리한다.
- 외부 계정은 암호화 저장하고 권한 있는 직원만 보기/복사할 수 있어야 한다.

### 업무

- 추가 업무는 매장, 업무명, 담당자, 긴급, 중요, 마감일, 상태, 증빙을 가진다.
- 마감일 경과는 진한 빨강, 당일은 주황, 미래는 기본색이다.
- 완료 시 완료일과 수행자가 기록되고 매장 히스토리 및 일마감에 남는다.
- 통화 요약 텍스트에서 업무 후보를 추출하되 직원이 수정·마감일 지정·승인한 항목만 등록한다.

### 매장 세팅

- 대문사진, 대문영상, 대표키워드, 상세설명, 찾아오는 길 후킹, 쿠폰 후킹, 공지사항 후킹, 메뉴 상단 3개, 메뉴 SEO/AEO, 세트/미끼메뉴를 월별로 점검한다.
- 진행률 0~100%, 마감일, 완료 여부, 비포/애프터 증빙을 저장한다.
- 1주차는 진단과 비포 수집, 3주차는 검수와 애프터 수집을 기본으로 한다.

### 데이터 업로드

- 플레이스 CSV와 여신금융 XLS 원본은 Storage에 보존한다.
- 중복 파일은 SHA-256으로 감지한다.
- 동일 매장/기간 재업로드는 버전을 남기고 최신본만 기본 조회한다.
- 업로드하지 않은 기간은 0으로 채우지 않는다.

### 키워드

- 그룹: 지역/장소, 수식어, 메뉴, 특수, 단독, 목표키워드
- 기본 조합: `1+3`, `1+2+3`, `1+2+4`, `1+4`, `2+3`, `2+4`, `5+3`, `5+4`
- 중복 제거와 공백 제거 옵션을 제공한다.
- 태그 CSV는 한 열당 50개, 파워링크 CSV는 한 열당 1000개로 분할한다.
- 저경쟁 탐색은 지도 페이지 수를 먼저 확인하고 3페이지 미만 후보만 검색량을 조회한다.

### 보고서

- 사장님에게는 수정 기능을 노출하지 않는다.
- 회사 수행 업무와 사장님 미션을 분리한다.
- 기간과 데이터 출처를 표시한다.
- 업무 증빙, 키워드 순위, 유입, 매출, 고객/결제 지표를 한 리포트로 묶는다.

## 6. 디자인 가이드

- 기존 ERP처럼 밝은 배경, 고밀도 표, 고정 사이드바를 유지한다.
- 카드 남발을 피하고 반복 비교는 표를 우선한다.
- 주차는 1주 초록, 2주 흰색, 3주 주황, 4주 진한 빨강으로 구분한다.
- 정상 초록, 주의 노랑/주황, 위험은 적녹색약에서도 구분되는 진한 빨강, 데이터 없음은 회색이다.
- 색만으로 의미를 전달하지 않고 아이콘/텍스트/툴팁을 함께 쓴다.
- 표 헤더는 한 번 누르면 오름차순, 다시 누르면 내림차순으로 토글한다.
- 사장님 보고서는 내부 ERP보다 쉬운 표현과 큰 핵심 수치를 사용한다.

## 7. 제약 사항

- 네이버 지도 DOM은 변경·차단될 수 있으므로 별도 브라우저 워커가 필요하다.
- Vercel 함수는 장시간 크롤링/대량 작업에 적합하지 않다.
- 검색광고 API 쓰기는 실수로 비용을 발생시킬 수 있으므로 승인형으로 제한한다.
- 플레이스 CSV와 여신금융 XLS 스키마 변경에 대비해 파서 버전과 경고를 저장한다.
- 마스킹 카드번호는 고유 고객 식별자가 아니다. 신규/재방문은 추정 또는 별도 고객키 확보 이후에만 확정한다.
- 계정 비밀번호와 API Secret은 평문 DB/로그/Git에 저장하지 않는다.
- 개인정보와 고객 동의는 매장별로 분리하고 삭제 요청을 처리할 수 있어야 한다.
