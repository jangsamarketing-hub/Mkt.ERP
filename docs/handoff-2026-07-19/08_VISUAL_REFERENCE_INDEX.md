## C. 이미지 사용 원칙

- 현재 스크린샷은 구현 상태 확인용이다.
- 참고 이미지는 목표 흐름과 밀도를 설명하는 설계 자료다.
- 새 개발자는 둘 중 하나를 임의로 버리지 말고 `03_PAGE_LOGIC_SPEC.md`와 함께 비교한다.
- 페이지 개선 후 같은 이름으로 덮어쓰지 말고 날짜별 QA 캡처를 추가한다.
