# 네이버 검색광고 비즈머니 잔액 모니터

내부 주소: `/balance-monitor`

## 현재 동작

- 검색광고가 연결된 활성 매장의 최신 `erp_searchad_account_snapshots`를 읽는다.
- 50,000원 이하: 빨간 경고
- 100,000원 이하: 주황 주의
- 낮은 잔액부터 정렬한다.
- 경고는 매장·기준금액별로 한 번만 새로 열고, 잔액이 회복되면 자동 해제한다.
- 기존 검색광고 일일 수집이 끝난 뒤 경고 원장을 갱신한다.

## 이메일 알림 설정

Vercel 환경변수에 아래 **이름만** 등록한다. 실제 값은 문서나 Git에 저장하지 않는다.

| 이름 | 용도 |
| --- | --- |
| `RESEND_API_KEY` | 이메일 발송 API 키 |
| `BALANCE_ALERT_EMAIL_TO` | 경고 수신 이메일 주소 |
| `BALANCE_ALERT_EMAIL_FROM` | 발신 승인 주소 |

세 값 중 하나라도 없으면 화면 경고와 원장 기록만 남기고 이메일은 보내지 않는다.

## 수집 시간

현재 Vercel Cron은 매일 11:00 KST에 검색광고를 수집하고 잔액 경고도 평가한다. 17:00 KST 추가 수집은 현재 요금제에서 지원하는 외부 스케줄러 또는 상위 Vercel Cron 요금제가 준비된 뒤 같은 엔드포인트를 호출해 추가한다.

## 롤백

`erp_searchad_balance_alerts` 테이블만 제거하면 된다. 기존 검색광고 스냅샷·캠페인 원장은 변경하지 않는다.
