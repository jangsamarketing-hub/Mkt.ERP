# 개발 진행 규칙

## 토큰 절약 원칙

- `search-first`: 파일을 크게 읽기 전에 `rg` 검색으로 위치를 먼저 찾고, 필요한 줄만 제한해서 읽는다.
- `tdd-workflow`: 최소 범위만 수정하고, 전체 파일 재작성은 피한다.
- `strategic-compact`: 대화가 길어지면 중간 설명을 버리고, 필요한 파일과 규칙만 다시 검색해서 이어간다.

## 현재 적용 기준

- 탐색/검색은 서브에이전트 또는 검색 우선 방식으로 비용을 줄인다.
- 추론 토큰은 `MAX_THINKING_TOKENS 10,000` 기준을 유지한다.
- `index.html` 또는 큰 파일은 전체 읽기 대신 offset/limit 방식으로 필요한 구간만 확인한다.

## 작업 단위

- 한 번에 한 화면 또는 한 기능만 구현한다.
- 구현 전 요구사항을 짧게 재정리하고, 애매한 부분은 확인한다.
- 구현 후에는 빌드 또는 최소 검증 결과를 남긴다.
