# 개발 진행 규칙

## 토큰 절약 원칙

- `search-first`: 파일을 읽기 전에 `rg`로 위치를 먼저 찾고, 필요한 줄만 제한해서 읽는다.
- `tdd-workflow`: 최소 범위만 수정하고, 전체 파일 재작성은 피한다.
- `strategic-compact`: 대화가 길어지면 과거 대화 전체를 다시 쓰지 말고 문서와 코드에서 필요한 사실만 다시 확인한다.

## 작업 단위

- 한 번에 한 화면 또는 한 기능만 구현한다.
- 기능 추가 전 데이터 흐름과 저장 위치를 먼저 확인한다.
- 구현 후에는 최소한 `npm run build`로 깨짐 여부를 확인한다.
- 외부 API, 크롤링, 자동화는 실제 차단 가능성을 먼저 검증한다.

## 현재 우선 개발 순서

1. 키워드 조합기와 CSV 다운로드 안정화
2. 네이버 플레이스 CSV 업로드/분석
3. 꿀키워드 탐색기 구조 개선
4. 여신금융 매출 엑셀 분석
5. 업무/보고서/매장 히스토리 DB 연동
