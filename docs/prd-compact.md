# 맞춤장사 OS 압축 PRD

## 1. 프로젝트 개요

맞춤장사 OS는 음식점 마케팅 대행사가 여러 매장의 90일 세팅과 반복 운영을 표준화하는 내부 ERP다. 매장 등록, 광고/플레이스/매출 데이터, 업무, 세팅 체크, 사장님 보고서를 매장 단위로 연결한다. 초기에는 수동 CSV/XLS 업로드와 관리자 검수로 시작하고, 검증된 흐름만 자동화한다.

## 2. 사용자 시나리오

- 관리자/대표: 전체 매장의 주차, 위험 신호, 매출·유입·광고·업무 상태를 비교하고 관리 미흡 매장을 찾는다.
- 매니저: 매장을 등록하고, 주간업무와 추가 약속 업무를 수행하며, CSV/XLS와 증빙을 업로드한다.
- 사장님: MID 기반 읽기 전용 링크에서 이번 주 업무, 성장 데이터, 목표와 진행상황을 확인한다.
- 향후 고객: QR 미니웹앱에서 동의, 설문, 포인트, 리뷰 안내와 이벤트에 참여한다.

## 3. 핵심 기능 목록

### MVP

1. 매장 등록/수정/삭제/엑셀 일괄등록
2. 4주 관리 주차와 월별 히스토리
3. 운영 대시보드와 정렬/필터/신호등
4. 플레이스 주간 CSV 업로드와 키워드/채널 분석
5. 여신금융 XLS 업로드와 매출·신규·재방문 분석
6. 1~6번 키워드 조합기와 50/1000 단위 CSV
7. 지도 페이지 수 우선 꿀키워드 후보 추출
8. 관리자 일일업무, 일일업무, 주간업무와 매장별 히스토리
9. 세팅 체크리스트와 증빙 이미지
10. 정보안내문 전역 템플릿과 매장별 답변
11. 사장님 보고서 미리보기와 읽기 전용 공유 링크

### 이후

- Supabase Auth/RBAC
- Playwright 상시 워커
- 검색광고 자동 세팅/태그 등록
- 네이버 플레이스 자동 수집
- 통화 녹음 전사와 업무 자동 후보화
- QR 리뷰/CRM 고객 DB와 이벤트 앱 연동
- 일마감, EXIT/권리금 리포트

## 4. 화면 구성

- 운영 대시보드
- 네이버 광고
- 유입/키워드 분석
- 여신금융 매출
- 관리자 일일업무
- 일일업무
- 주간업무
- 사장님 보고서
- 매장 정보
- 정보안내문
- 매장 주간 데이터 흐름

모든 매장별 화면은 상단 업체 선택기를 사용하며, 선택하지 않은 상태에서는 분석 수치를 표시하지 않는다.

## 5. 상세 기능 명세

- Store를 기준 엔터티로 삼고 모든 CSV, 매출, 키워드, 업무, 보고서, 히스토리를 `store_id`와 연결한다.
- Place CSV는 파일 기간을 보존하고 주간 월요일~일요일로 조회한다.
- Sales XLS는 원본 파일을 보존하고 거래 행을 정규화한 뒤 신규/재방문을 추정한다.
- Keyword Job은 입력 조합, 생성 결과, 지도 검사 상태, 검색량 상태, 등록 여부를 저장한다.
- 지도 검사는 `map.naver.com/p/search`를 브라우저에서 수행한다. 페이지 수 3 미만을 1차 후보로 보고 검색량은 2차 분석한다.
- Task는 업체, 제목, 마감일, 긴급, 중요, 상태, 담당자, 증빙, 완료일, 히스토리를 가진다.
- Checklist는 업체별 월/주차 기록을 분리해 다음 달에도 이전 기록을 보존한다.
- Owner report는 읽기 전용 토큰 링크이며 내부 계정과 비밀번호를 포함하지 않는다.

## 6. 디자인 가이드

- 현재 ERP처럼 밝고 표 중심인 업무 화면
- 좌측 고정 메뉴, 상단 업체 선택/기간/필터, 본문 표와 그래프
- 초록은 정상, 주황은 주의, 진한 빨강은 위험, 회색은 데이터 없음
- 적녹색약을 고려해 색상만으로 판단하지 않고 라벨, 수치, 아이콘을 함께 표시
- 핵심 판단은 표에서 먼저 가능하고 그래프는 보조로 사용

## 7. 제약 사항

- 네이버/플레이스 화면 구조와 자동화 차단에 따라 지도 검사가 실패할 수 있다.
- Vercel 서버리스만으로 긴 브라우저 작업을 수행하지 않고 별도 워커를 둔다.
- CSV/XLS 형식이 바뀌면 파서 버전 관리가 필요하다.
- 여신금융 신규/재방문은 카드사+마스킹 카드번호 기준의 추정값이다.
- 데이터 없는 기간은 0이 아닌 데이터 없음이다.
- 실제 API 키와 계정 비밀번호는 저장소에 커밋하지 않는다. 과거 채팅에 노출된 키는 교체한다.

## 8. 기술 스택

- Next.js, TypeScript, React, Tailwind CSS, Vercel
- Supabase PostgreSQL, Storage, Auth
- 서버 API Route와 Zod 기반 입력 검증
- CSV/XLS 파싱 모듈과 원본 파일 보관
- Recharts 또는 동등한 차트 라이브러리
- Playwright/Chromium 기반 지도 검사 워커
- 추후 Trigger.dev, Inngest 또는 Queue 기반 작업 처리
