## 4. 제품 의도 메모

### 제품의 역할

- 단순 마케팅 SaaS가 아니라 90일 동안 매장에 맞는 성장 구조를 세팅하는 운영 OS
- 대표의 판단을 표준화해 직원이 전문가처럼 실행
- 사장님에게 `우리 회사가 한 일`, `사장님이 해야 할 일`, 실제 데이터 변화를 분리해 보여줌
- 대표가 무제한 CS와 반복 확인에서 벗어나도록 함

### 관리의 핵심

- 후행지표 매출보다 선행지표인 결제패턴 수와 건당결제액의 방향을 먼저 본다.
- 상권은 낚시터, 고객은 물고기, 전략은 그 물고기에 맞는 미끼라는 구조로 설명한다.
- 매장 순위는 경쟁업체가 아니라 우리 매장의 등록 키워드 변화만 관리한다.
- 알림톡/이메일/Slack 순위 알림은 최종 영역으로 보류한다.

### 데이터 운영

- 매주 월요일 직원이 Tampermonkey로 Place 주/월 JSON 또는 CSV를 받아 업로드한다.
- 여신금융 XLS/XLSX도 직원이 같은 import control plane으로 업로드한다.
- 자동수집은 수동·반자동 루틴이 안정된 뒤에 검토한다.

### 검색광고 상품

- 기본형: campaign draft, 키워드/태그 조합, preview, 관리자 승인, 제한 실행
- 프리미엄: 30분 순위 감시와 CPC 자동조정
- 프리미엄 기능은 read-only·shadow mode·원복 검증 뒤에만 제공한다.
