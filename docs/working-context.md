# 맞춤장사 OS 작업 기준점

## 현재 상태
- Next.js 기반 ERP 프로토타입이 로컬에서 동작한다.
- GitHub 저장소: `jangsamarketing-hub/Marketing.ERP`
- Vercel 프로젝트: `do-sun/naver-place-marketing-erp`
- 2026-07-13 기준 Vercel 무료 배포 횟수 제한으로 프로덕션 배포는 24시간 뒤 재시도 필요.

## 토큰 절약 규칙
- 작업 시작 전 전체 파일을 읽지 않는다.
- `rg`로 위치를 먼저 찾고 필요한 줄만 읽는다.
- 수정은 페이지 단위 또는 기능 단위로 작게 진행한다.
- 긴 대화 맥락은 이 문서, `prd.md`, `visual-references.md`를 기준점으로 삼는다.
- 매번 과거 대화 전체를 재요약하지 않는다.

- 관리자 일일업무

## 다음 개발 우선순위 제안
1. 키워드 조합기
   - 외부 API 없이 로컬 로직으로 먼저 완성 가능
   - 50개 태그용 CSV, 1000개 파워링크용 CSV 다운로드까지 바로 검증 가능
2. 네이버 플레이스 CSV 유입키워드 분석
   - 수동 CSV 업로드 기반이라 자동화 리스크가 낮음
   - 운영 대시보드의 네이버 유입 데이터와 연결 가능
3. 여신금융 매출 데이터 분석
   - 엑셀 파싱과 신규/재방문 추정 로직 필요
   - 매출/객단가/재방문률/목표 고객수 계산과 연결
4. 네이버 검색광고 API
   - 계정별 키, 서명, API 제공 범위 검증이 먼저 필요
   - 비즈머니 잔액과 광고 성과 조회 가능 여부를 초기에 작은 API 테스트로 확인

## 개발 병목 순서
- 가장 병목이 적은 순서: 키워드 조합기 → CSV 유입키워드 분석 → 여신금융 엑셀 분석 → 네이버 검색광고 API
- 이유: API/로그인/외부 정책 의존도가 낮은 기능부터 완성해야 개발 속도가 안정적이다.
