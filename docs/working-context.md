## 현재 확인된 핵심 이슈
- 네이버 지도 페이지수 확인 API는 Vercel 서버에서 `blocked` 응답이 발생한다.
- 이 경우 화면에는 `지도차단`으로 표시한다.
- 네이버 지도 페이지수는 서버 API만으로 안정 구현하기 어렵고, 브라우저 기반 워커나 반자동 확인 플로우가 필요하다.
- 네이버 검색광고 API 환경변수는 Vercel Production에 등록했다.
- 로컬 직접 호출 기준 네이버 검색광고 API는 HTTP 200으로 응답한다.
- 단, Vercel 무료 배포 횟수 제한으로 2026-07-13 현재 재배포가 막혀 있어 운영 URL에는 환경변수 반영이 아직 안 됐다.
- 검색광고 API는 지도 페이지수 확인이 성공한 저경쟁 키워드에만 후순위로 실행하는 구조가 맞다.

## 개발 병목이 적은 순서
1. 키워드 조합기
   - 조합 생성, 초기화, CSV 다운로드, 50개/1000개 열 분할을 먼저 안정화한다.
2. 네이버 플레이스 CSV 유입/키워드 분석
   - 매장별 주간 CSV 업로드, 저장, 기간 조회, 증감 비교를 구현한다.
3. 꿀키워드 탐색기
   - 지도 페이지수 확인은 브라우저 워커/반자동 구조로 분리한다.
   - 검색광고 조회수는 페이지수 3 미만 후보에만 붙인다.
4. 여신금융 매출 데이터 분석
   - 엑셀 업로드, 날짜별 매출, 신규/재방문 추정, 목표매출 기반 필요 고객수 계산을 구현한다.
5. 업무/보고서 연동
   - 완료 업무, 통화 히스토리, 매장 세팅 체크리스트, 사장님 보고서 반영을 DB 기반으로 연결한다.
